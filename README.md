# TransitMateSG

TransitMateSG is a React Native mobile application developed using Expo to support public transport commuters in Singapore.

The application combines live bus arrival information, nearby bus stops, route information, location services, notifications, and weather information in a single mobile application.

## Key Features

- Live bus arrival information using LTA DataMall
- GPS-based nearby bus stop detection
- Interactive map showing nearby bus stops
- Search for bus stops by stop code, name, or road
- View full bus routes
- Bookmark frequently used bus stops
- Bus arrival notifications
- Current weather information and 3-day forecast
- Manual location selection
- Local caching of bus stop and route data

## Technologies Used

- React Native
- Expo
- JavaScript
- LTA DataMall API
- Open-Meteo API
- AsyncStorage
- Expo Location
- Expo Notifications
- Git
